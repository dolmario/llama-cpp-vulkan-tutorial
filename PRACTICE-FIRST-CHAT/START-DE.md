# Dein erster lokaler Chat

Die vollständigen Befehle, Modellquelle und das tatsächlich erzeugte Browserbeispiel stehen in [README.md](README.md).

INSTALL-LLAMA.ps1 lädt die Vulkan-Laufzeit in einen neuen Ordner. DOWNLOAD-MODEL.ps1 lädt und prüft die separate GGUF. START-LLAMA.ps1 startet den Server im Vordergrund mit Kontext4096 und Port18190. Im Browser öffnen: http://127.0.0.1:18190. TEST-API.ps1 sendet dieselbe Beispielaufgabe und speichert die tatsächliche JSON-Antwort. Beenden mit Strg+C im eigenen Serverterminal.
